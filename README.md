# BrainTrain

A single-file memory training game built on techniques with research behind them:

- **Word palace** – method of loci (Dresler et al., 2017, *Neuron*)
- **Numbers** – the Major System for chunking digits (Ericsson, Chase & Faloon, 1980, *Science*)
- **Major drill** – spaced repetition of the 00–99 image code using Leitner boxes (Cepeda et al., 2006)
- **Names & faces** – elaborative encoding on generated portraits
- **Echo recall** – delayed retrieval practice (Roediger & Karpicke, 2006)

The app includes XP, levels, a daily streak, badges, and difficulty that adapts after each round.

Progress is stored in the browser's `localStorage` on your device. Nothing is sent anywhere. Use the backup code on the Progress tab to move your progress between browsers or devices.

## Run it

Open `index.html` in any browser. There is no build step. It works offline once the fonts have been cached.
